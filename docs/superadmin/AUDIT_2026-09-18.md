## Dónde vive el administrador anterior

## Hallazgos de seguridad

1. `app_metadata` todavía no es la fuente de autorización administrativa.
2. `public.radar_authorized_voter_communities(text)` es `SECURITY DEFINER` y ejecutable por `authenticated`; debe revisarse antes de integrar este frente.
3. La protección de contraseñas filtradas está desactivada.
4. Las cuentas administrativas no tienen MFA/AAL2 exigido por políticas del sistema.
5. Las tablas privadas de semilla tienen RLS sin políticas; esto es correcto si permanecen cerradas, pero debe documentarse y mantenerse fuera de esquemas expuestos.
6. Hay 13 claves foráneas sin índice de cobertura y 18 combinaciones con políticas permisivas duplicadas; son mejoras de rendimiento, no autorización para alterar producción desde este frente.

## Decisión de integración

La consola se integrará en este repositorio como un shell protegido propio bajo `/admin/*`, sin alterar el dashboard municipal. El Site anterior no se importará como fuente ni se conectará mediante estados copiados. El frontend administrativo consumirá una API administrativa de servidor que entregue agregados mínimos; las operaciones privilegiadas usarán Edge Functions y funciones SQL auditadas. Las migraciones se revisarán y aplicarán primero en una rama Supabase QA.
